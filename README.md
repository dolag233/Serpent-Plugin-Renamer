# Serpent Plugin Renamer

Serpent 官方批量重命名插件。选中资产后，在右键菜单中选择“批量重命名”（英文界面显示 “Batch Rename”）。插件会跟随 Serpent 的界面语言显示中文或英文。

## 功能

- 添加前缀或后缀，扩展名保持不变。
- 使用“查找内容”和“替换为”批量替换文件名。
- 使用“自动编号”为选中的资产按顺序或倒序编号，可设置起始数字、普通数字/补零数字/括号格式、编号位置和 `_x` 等分隔格式。
- `Aa` 用于切换是否区分大小写，`.*` 用于切换普通文本或正则匹配。
- 前缀和后缀、字符串替换、自动编号分别位于独立标签页，命名预览固定显示在窗口底部。
- 应用前在可滚动的列表中预览原文件名和新文件名；匹配内容以蓝色标记，改动内容以黄色标记。
- 预览列表支持较长文件名换行显示；文件名冲突会提示，冲突项不会覆盖原文件。

## 安装与使用

在 Serpent 的「设置 → 插件 → 打开插件社区」中安装「批量重命名」。也可以用高级安装选择本地插件目录或 Release ZIP。信任并启用后，回到资源库，选中一个或多个资产，打开右键菜单并选择「批量重命名」。填写规则后检查预览，点击「应用」即可。

## 开发

```bash
npm test
npm run check
```

插件使用 Serpent Host 的标准 `serpent.ui.openDialog`、`ui.list`、`ui.group` 和 `ui.tabs` 控件，不需要额外依赖或构建步骤。
