# Serpent Plugin Renamer

Serpent 官方批量重命名插件。选中一个或多个资产后，在右键菜单中选择“批量重命名”。

## 功能

- 添加前缀或后缀（扩展名保持不变）。
- 按关键词替换文件名中的文本，并单独指定关键词替换结果。
- 使用正则表达式匹配和替换，并单独指定正则替换结果；支持自定义正则选项（默认 `g`）。
- 应用前先在 Finder 风格的交替行列表中预览原文件名与新文件名。
- 同一批次中的重名和宿主发现的文件名冲突会显示为提示，冲突项不会覆盖原文件。

## 安装

在 Serpent 的“设置 → 插件”中安装本地目录或 Release ZIP，信任并启用插件。随后在资源库中选中资产，打开右键菜单即可使用。

## 开发

```bash
npm test
npm run check
```

插件使用 Serpent Host 的 `serpent.ui.openDialog` 和 `ui.list` 标准控件，不需要额外依赖或构建步骤。
